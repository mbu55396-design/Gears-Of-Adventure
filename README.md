# Gears-Of-Adventure
A big messy mix of Crazy Craft, ATM10, and Better MC for 1.20.1 Forge. New worlds, Create, and way too many weird mobs.
couldn’t decide between Crazy Craft, RLCraft, All the Mods 10, and Better Minecraft, so I just made a pack that’s all four at once. Instead of picking one mod per category, I kept the overlapping ones and spent way too long getting them to play nice together.

The worldgen is a big part of it. Terralith, Tectonic, Biomes O’ Plenty, and Regions Unexplored all stack, so the overworld looks pretty wild, and Better Nether and Better End fix up the other dimensions. Create is in there too if you want to build machines.

The start is pretty normal, so you won’t die to a tree on day one like in RLCraft. That doesn’t last. Once things get going, survival gets awful fast, and the world gets more insane the further you go.

And then there’s the mobs. OreSpawn is back, along with Lycanites Mobs and a bunch of other Crazy Craft stuff, and they’re all just out there in the world with you. Build your base with that in mind.
